# Movie Rating Prediction

This project predicts movie ratings using machine learning.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Steps
1. Data cleaning and preprocessing
2. Feature selection (Genre, Duration, Votes)
3. Model training using Random Forest
4. Evaluation using R2 Score
5. Visualization of Actual vs Predicted ratings

## Result
The model achieved a reasonable R2 score and predictions were visualized using a scatter plot.
