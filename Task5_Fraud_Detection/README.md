# Credit Card Fraud Detection


This project detects fraudulent transactions using machine learning.

## Problem
Highly imbalanced dataset where fraud cases are very rare.

## Approach
- Data preprocessing
- Handling imbalance using oversampling
- Model training using Random Forest
- Evaluation using precision, recall, and F1-score

## Dataset
Dataset is too large to upload.  
Download from Kaggle:  
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## Result
The model was able to detect fraudulent transactions effectively.

![Result](result.png)

## Key Insight
Accuracy is not reliable for imbalanced datasets. Precision and recall are more important.
